# 新增 UI 复核（dev）

## 修复范围

- 搜索：使用 shadcn Command / cmdk 结构，输入框左右留边；空结果居中；统计与快捷键放入有内边距的页脚。支持方向键、Enter、Escape，使用 DialogTrigger 恢复关闭后的焦点。
- 历史：统一 DialogBody、Empty、Button；空状态保留高度，记录卡片与弹窗留边，长结果独立滚动，清空操作放入页脚。
- 文档：采用 Radix/shadcn Tabs，48px 文档栏、36px 标签，下划线标识当前项；关闭当前文档和新建按钮独立放置。支持方向键、关联 tabpanel、关闭撤销、12 文档上限和选中项随窗口调整自动滚入可见区。
- 其他新增 UI：授权预览补内容区边距；小Q上下文复用 Accordion；页面错误使用有内边距的卡片与共享 Button；编辑器补焦点指示、错误定位按钮，移除转换页包裹按钮的 label；工具选择器统一圆角与焦点样式。补齐新增历史与错误文案的英文翻译。
- 复核 AssistantMessageFlow、MarkdownRenderer 的上轮差异：主要是翻译接入，保留现有 Accordion 和排版规则。

没有全局修改 DialogContent 的默认 padding，避免影响已有弹窗自行设置的内容区。新增 cmdk 1.1.1；Tabs 使用已安装的 radix-ui。

## 验证证据

通过 shadcn MCP 查阅 Command、Tabs、Empty 示例及 audit checklist，并用项目配置的 radix-nova CLI dry-run 源码对照适配；没有覆盖项目既有 Button/Dialog 文件为注册表默认版本。

Playwright CLI 使用独立临时浏览器会话，在本地 Vite 页面验证：

- `npm --prefix frontend run test:ui`：原有功能回归通过，包括文档隔离、页面缓存、搜索、1000×618 小Q侧栏、正则超时、无页面三步工作流和授权取消。
- `npm --prefix frontend run test:ui:audit`：新增 UI 检查通过，包括空/非空记录、搜索输入与页脚边距、键盘搜索与标签、关闭撤销、错误定位焦点、640×520 / 1000×618、深浅主题、中英文、12 文档布局、授权预览、上下文及错误长文本。
- `npm --prefix frontend test`：14/14 通过。
- `npm --prefix frontend run build`：TypeScript 和生产构建通过；现有大 chunk 提示仍存在。项目没有独立 lint 脚本。
- `npm --prefix frontend run check:release`：生产产物不包含测试入口、CLI 标识和故障演示标识。
- `git diff --check`：通过。

截图和 CLI 日志保存在忽略目录 `output/playwright/`。代表截图为 `history-light.png`、`search-light.png`、`documents-light.png`、`documents-dark-narrow.png`、`search-english.png`、`history-filled.png`、`permission.png`、`assistant-context.png` 和 `page-error.png`。

验证范围是 Chromium 中的真实前端；浏览器无 Wails 原生桥接时出现的配置读取通知不代表桌面配置验证结果。本轮未调用真实 AI 服务或远程 MCP。测试故障和权限场景仅位于 tests/harness.tsx，正式应用不导入它。
