# 编辑器与预览修复

本轮保留在 dev，未合并 main。小Q权限逻辑未扩大：文件开关仅控制已选文件批量重命名与撤销是否免逐次确认；MCP 文件操作仍走独立 MCP 权限。设置中补充了这段范围说明。

- Mermaid 移除固定 28rem 高度与 32rem 最小宽度，依据实际图表高度调整画布（120–480px）。平移与内容是否溢出解耦，小图也能拖动；保留缩放、滚动条、复位和全屏。
- 文本工作台预览内容区改为自然高度及最大高度，短图不再强制占用整个预览区域。
- CodeEditor 行号成为独立列，文字横向滚动不覆盖行号。垂直同步采用位移，避免不同平台横向滚动条占高造成末行错位。
- 设置增加“显示编辑器行号”，默认开启，作用于所有 CodeEditor 输入/输出，存于隔离的界面偏好中并立即生效。
- JSON Schema 恢复较大、可纵向调整的编辑区。粘贴按光标与选区插入后使用已有无损 JSON 格式化；失败保留文本并 toast 提示可请小Q修复，不自动发送 Schema 到模型。
- 正则替换区未删除：现在直接位于替换模板下方，有标题、复制按钮和处理/空结果/取消/失败状态。载入正则示例同时恢复 `$<host>` 模板；提示其引用 `(?<host>...)` 命名组。

验证：19 项单元测试通过；Playwright CLI 的 test:ui、test:ui:regressions 和 test:ui:editors 通过。编辑器专项实测长文本横纵滚动、行号开关和重载持久化、小 Mermaid 自适应高度和鼠标拖动、JSON Schema 粘贴成功/失败、`$<host>` 与 `[$<host>]` 的真实替换结果。TypeScript/生产构建和发布入口隔离检查通过，已有大 chunk 提示保留。

截图与日志存放于忽略目录 output/playwright；代表截图为 editor-long-scroll.png、mermaid-adaptive-pan.png、schema-paste.png、regex-replacement-visible.png。测试在 Chromium 中运行，未进行修改文件操作，也未调用模型修复服务。


## 正则替换交互补全

根据后续确认，将查找表达式、替换为、原始文本及替换结果明确分开。替换为支持多行文本、空字符串删除和捕获组引用；保留查找匹配按钮，新增执行替换与复制结果。原始文本不被自动覆盖，自动预览作为辅助信息放到下方。

替换通过注册表的 validation.run（action=replace）执行，复用 Worker 超时隔离及执行记录，可供工作流使用。修改保留在 dev，尚未合入 main。

## 正则页面两组布局

按后续确认重构为“输入与查找匹配”和“替换与结果”两张卡片，宽窗口左右布局，窄窗口上下排列。查找组包含表达式、Flags、原始文本、查找按钮和匹配结果；替换组包含固定高度且禁止拖动缩放的替换输入、执行按钮和替换结果。移除重复的自动替换预览，匹配高亮折叠在输入组内。

匹配结果与替换结果分别保存在文档模型中，执行其中一个操作不再覆盖另一个结果。业务仍经统一注册表和 Worker 执行。

## 正则田字格布局与聚焦样式

按最终反馈将表达式、Flags 和查找操作放在顶部，下方连续四格依次为原始文本、匹配结果、匹配高亮与替换输入、替换结果。桌面两列，窄屏按顺序单列；测试用例和生成代码位置保持不变。替换输入仍禁止拉伸，匹配高亮直接显示。

CodeEditor 统一内部文本框为无圆角、无独立边框和阴影，聚焦时只在包含行号的整体编辑区显示细轮廓，避免双重聚焦装饰。这项统一样式同时覆盖其他使用 CodeEditor 的页面。

## 执行按钮切换为停止

移除独立取消预览按钮。查找匹配、执行替换在请求进行中分别显示停止查找、停止替换，同一按钮再次点击通过 AbortSignal 终止对应 Worker；同时暂时禁用另一执行按钮。取消保留之前结果并显示停止提示，完成、停止或超时后恢复按钮，可重新执行。组件卸载时取消未完成的手动任务。

自动高亮保留输入变化时的取消和超时保护，独立 highlight Worker 作业只计算高亮，不再计算未显示的替换预览；替换内容变化不触发高亮。

验证：19 项前端测试通过；Playwright CLI 检查耗时查找/替换的开始、停止、互斥按钮、结果保留及重新执行，编辑器交互和核心超时回归通过；生产构建和发布隔离检查通过。变更保留在 dev。
