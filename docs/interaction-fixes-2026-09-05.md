# 执行记录、输入提醒、文档编号与剪贴板修复

分支：dev。本次修复独立于上一轮 UI 样式提交，未合并 main。

## 行为变化

- 校验页手动执行和批量正则测试接入统一执行记录；格式化、转换保持原入口。顶部显示当前记录数量。实时正则预览不写入历史。
- 加密、标识符生成、Cron、网络原生调用、文件操作和 MCP 手动调用补状态记录。此类记录不导出密钥、解密文本或原生响应，结果仍在工具页面；状态记录不能作为工作流输入或转交格式化工具。历史依然仅保留当前会话，最多 40 条。
- 校验工具栏将表达式与按钮组分开布局，按钮不再被两列网格拉满。“取消预览”仅正则模式显示，只有预览等待或运行期间可用，取消后不再写入旧预览结果。
- 校验、格式化和转换共享输入提醒：保留旧输入切换工具时明确提示；输入修改后进行 250ms 防抖基础格式检查。覆盖 JSON、XML、YAML、TOML、正则语法、CSS Selector/XPath 表达式、Base64/URL 编码、字节与进制格式。JSON Schema 检查 JSON 及顶层形态，完整模式约束仍在执行时检查。大于 200,000 字符的输入跳过自动检查。
- 输入提醒不执行转换、正则匹配、查询或网络请求，也不覆盖用户文档。复杂语言语义和业务正确性仍以执行结果为准。转换页补上对应来源的“载入示例”。
- 文档序号按工具会话递增，不按剩余文档数量生成；删除文档 1 后新增得到文档 3，撤销关闭也不会导致重名。
- 程序化复制统一标记为应用内部写入，原生选择复制也更新检测基线；异步读取用版本号避免竞态，页面切换和内部复制会撤下过期提示。首次启动和相同内容再次获得焦点不提示。
- 自动识别使用更保守的完整格式检查：URL 优先，JSON 限对象/数组，XML 要可解析，JWT 检查头和载荷结构，Base64 检查 UTF-8 文本。纯文本、纯数字、易混淆 YAML/Cron 不再自动弹提示。点击提示时立即将内容送入对应工具，移除延迟填入造成的导航竞态。

## 验证

- 单元测试 19/19：含文档删除/新增/撤销编号、内部复制与异步读取竞态、识别歧义、输入格式及大输入限制、原生操作记录不携带敏感结果。
- Playwright CLI `test:ui:regressions`：手动校验恰有一条记录；预览不污染历史；取消预览；1000×618 与 640×520 工具栏；三个页面的执行前提醒；文档编号；应用共用复制函数写入后不会被检测为外部内容。复制测试结束恢复剪贴板原值。
- Playwright CLI `test:ui`：原有缓存、精度、文档隔离、搜索、正则超时、无页面三步工作流和权限取消回归通过。
- Playwright CLI `test:ui:audit`：上一轮深浅主题、中英文、标签和弹窗审查通过。
- TypeScript / Vite 生产构建、发布产物隔离检查、git diff --check 通过。已有大 chunk 提示未在本次扩展处理。
